(git)
cmd操作：
>>git --version 看git版本
>>git init 初始化檔案(此時會有.git隱藏檔)
>>git status 查看狀態
>>git add . (.是當前位置所有檔案) 上傳當前檔案

>>git commit -m "你的訊息" 為commit留下備註（系統強制寫備註）
此時會要求給github帳號與使用者名稱
依序輸入後再git commit -m "你的訊息"，git status，
出現
On branch master
nothing to commit, working tree clean
即代表成功
（到目前為止都是本地端行為，沒有到github裡）

（底下在github新專案建立時，頁面中間會有提示詞可以複製）
>>git branch -M main 設定branch為main
>>git remote add origin https://github.com/sidleecodev/travel-food.git  傳到指定的github專案
>>git push -u origin main 上傳檔案

上傳後要開啟作品，可以github→Settings→Pages，把Branch的none改成main，
回到專案頁面，About部分有個齒論，進去後Website的Use your GitHub Pages website勾選起來，
儲存後會有連結可以點。
網頁預設上需要專案中有"index"的檔名才能展示，要開啟指定檔案，可以在想要展示的網址後面補上指定檔案名稱。
例：https://sidleecodev.github.io/travel-food/
欲展示檔案名稱：(AI)practice_JSON_travelfood.html
需輸入https://sidleecodev.github.io/travel-food/(AI)practice_JSON_travelfood.html


(Bootstrap)
Bootstrap是一組用於網站和網路應用程式開發的開源前端框架，
包括HTML、CSS及JavaScript的框架，
提供字體排印、表單、按鈕、導航及其他各種元件及Javascript擴充套件，
旨在使動態網頁和Web應用的開發更加容易。
